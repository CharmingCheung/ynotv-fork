# FFmpeg MOV packet lab

This is an isolated C experiment for feeding an initialization segment followed
by discrete fMP4 media fragments to FFmpeg's MOV demuxer through a custom
`AVIOContext`. It is not linked to the ynoTV application.

```sh
./generate-fixtures.sh
./build.sh
./run-experiments.sh
```

Generated media and captured output are written below `fixtures/` and
`results/`; both directories are ignored. The input is synthetic video and
audio generated by FFmpeg filters.
